# CraftMods — دليل التشغيل والتخصيص

موقع عربي متجاوب ثابت (HTML + CSS + JavaScript) لعرض مودات Minecraft. لا يحتاج إلى تثبيت برامج أو قاعدة بيانات لعرض الموقع.

## تشغيل الموقع على جهازك
1. فك ضغط ملف `CraftMods.zip`.
2. افتح مجلد `CraftMods`.
3. افتح `index.html` في المتصفح.

## مهم قبل النشر
البطاقات الثلاث الحالية أمثلة تصميمية وليست مودات حقيقية. روابط التحميل تشير إلى ملفات داخل `mods/` يجب أن تستبدلها بملفاتك الفعلية.

## إضافة ملف مود حقيقي
1. ضع ملفك داخل مجلد `mods`، مثلاً `cool-addon.mcaddon`.
2. افتح `index.html` بمحرر نصوص.
3. انسخ كتلة `<article class="mod-card"...>` لبطاقة موجودة.
4. عدّل `data-title` و`data-category` والاسم والوصف والإصدار ونوع الملف.
5. عدّل رابط التحميل، مثال:
   `<a class="download-link" href="mods/cool-addon.mcaddon" download>تحميل <span>↓</span></a>`
6. حدّث رقم المودات في قسم المقدمة إذا أضفت أو حذفت بطاقات.

التصنيفات المتاحة للفلترة: `bedrock` و`java` و`tools`، ويمكن الجمع بينها في `data-category`.

## النشر المجاني على الإنترنت — GitHub Pages
1. أنشئ حساباً في GitHub إذا لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً باسم `craftmods` (يمكن جعله عاماً).
3. ارفع الملفات والمجلدات الموجودة داخل هذا المجلد، مع `index.html` في جذر المستودع.
4. افتح إعدادات المستودع: **Settings → Pages**.
5. في **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
6. انتظر اكتمال النشر؛ سيظهر رابط موقعك في صفحة Pages، عادةً بصيغة `https://اسمك.github.io/craftmods/`.

يمكنك أيضاً استخدام Netlify Drop لرفع مجلد الموقع أو أرشيفه من خلال واجهة Netlify، وفق الخيارات المتاحة حالياً.

## ملاحظات
- ملفات المودات الكبيرة قد تتجاوز حدود الرفع أو المستودع. للمشاريع الكبيرة، استضف ملفات المودات في خدمة ملفات مناسبة ثم ضع رابط التحميل المباشر في البطاقة.
- هذه نسخة ثابتة: لا توجد لوحة إدارة سرية أو تسجيل دخول. من يملك صلاحية تعديل المستودع يستطيع تعديل المحتوى.
- اختبر كل ملف مود بنفسك وتأكد من توافقه مع إصدار Minecraft وبيان أي متطلبات إضافية.
- لا تستخدم صوراً أو ملفات لا تملك حق نشرها.
